First release for WoW Forever.

One font for every addon: pick a font once and every addon that uses LibSharedMedia fonts (Plater, Details, SexyMap, Questie, MSBT, Dominos cast bars, Prat) uses it, without changing their settings. Optionally (on by default) the default UI too: chat, tooltips, quest text, keeping sizes and outlines. Bundles Inter SemiBold (Latin, Cyrillic, Greek).

Install: extract so the folder is Interface/AddOns/BubbleFonts. Settings: /bubblefonts
