# BubbleFonts

First release.

- One font for every addon that uses LibSharedMedia (Plater, Details, SexyMap, Questie, MSBT, Dominos
  cast bars, ...), through LibSharedMedia's global font setting. Other addons' settings are not
  changed.
- Optional (on by default): Blizzard UI fonts too (chat, tooltips, quest text), keeping sizes and
  outlines.
- Bundled font: Inter SemiBold (Latin, Greek, Cyrillic), SIL Open Font License.
- Settings panel and `/bubblefonts`.
